# SKC Facturas v1.5.1

## Nueva numeración

Reinicio del contador **visible** de versión, pasando de v3.15.5 a **v1.5.1**.
No se reinician los identificadores internos que Android utiliza para permitir actualizaciones,
ni los números de esquema de base de datos y formularios.

- Versión Android (versionName): `1.5.1`.
- Código interno Android (versionCode): `31506` (mayor que el anterior `31505`).
- Versión indicada en la sección Cuenta de Configuración: `v1.5.1`.
- Manifiestos y registros de exportación, copias de seguridad y ajustes: `1.5.1`.
- Portal web de descarga: `v1.5.1`, con lectura de Releases para mostrar versiones futuras automáticamente.
